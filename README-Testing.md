# Control Freak // Test Plan

Control Freak calls out taunts, interrupts, fears, loss of control, tank deaths and pet or priest mistakes while the fight is still going. This time we most want you to try the new Single Target / AOE dropdowns on the Taunts tab, and to tank real groups with it on.

**Play on Classic Era, Season of Discovery and TBC Anniversary.** If something looks wrong, tell us the check number and what you saw on [Discord](https://discord.gg/eh8hKq992Q).

## What's New

1. On the **Taunts** tab, read **Taunt Abilities**: every taunt now has a **Single Target** / **AOE** dropdown, locked on all of them except a paladin's **Righteous Defense** on TBC Anniversary.
2. On a TBC Anniversary paladin, set **Righteous Defense** to **Single Target** and cast it on a friend with several elites on them: each mob it pulls gets its own **Taunt!** line.
3. On a German, French, Spanish, Portuguese or Russian client, tick a class under **Deaths by Class** on **Tank Deaths**: when a female character of that class dies, her class is named in its feminine form.
4. On **Diagnostic Tools**, tick **Enable Diagnostic Tools** and run the big button on each of the **Settings**, **Code**, **Data** and **Localization** tabs: every report should fill in without an error.

## Everything Else

5. Log in with Control Freak as your only add-on: a welcome line prints, no error appears, and every sound in a **Play Sound** picker plays when you pick it.
6. While tanking, taunt an elite before it hits you: **Taunt!** prints with a clickable spell (check the link on Classic Era), and a resisted taunt sends **Taunt Failed!** to party chat.
7. As a warrior in a group, use **Challenging Shout** and then **Intimidating Shout** on a pack: one party-chat line each, not one per mob.
8. Interrupt a casting mob: the **Interrupt!** line names the spell you stopped (check on Classic Era).
9. On Season of Discovery, use a rune taunt such as **Hand of Reckoning**, **Tease**, **Menace** or **Demonic Howl**: it appears under **Taunt Abilities** and alerts like any other taunt.
10. While you tank, have a hunter or warlock leave their pet's taunt on auto-cast: **Bad Pet!** prints and the owner gets one whisper.
11. While you tank at high health, have a priest cast **Power Word: Shield** on you: **Bad Shield!** prints.
12. Die while tanking in a party, and again in a raid once you're set as Main Tank: **Tank Down!** prints with a sound each time.
13. Type `/freak`, then Shift + Middle-Click the mini-map button: each opens Control Freak inside the game's Options window with no **Apology** page left in its list (TBC Anniversary is where it used to float free), and in combat each refuses with a message instead.
14. Left-Click the mini-map button to turn every alert off and on, and Right-Click it to turn Tanking Tools off and on; the tooltip shows which is on.
